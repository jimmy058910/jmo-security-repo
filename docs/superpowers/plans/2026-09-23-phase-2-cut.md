# Phase 2 — Cut the matrix in one change: task plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** remove 16 tools, the scan-profile concept and three of four Docker images in
one PR into `dev`, leaving one 12-tool `TOOL_MATRIX`, one `Dockerfile`, and no stale
tool-count literal, and closing #1088 #1099 #1152 #1164 #1176 #1217 #1219 #1222 #1225.

**Architecture:** `scripts/core/tool_registry.TOOL_MATRIX` (12 names) replaces
`PROFILE_TOOLS`; the tool list resolves `--tools` > `jmo.yml tools:` > `TOOL_MATRIX`, and
content decides which of the 12 execute on a target. opa leaves the matrix as
`POLICY_ENGINE`: still installed and still in the image, but not a scanner. Profile
data leaves every stored surface: the history DB drops `scans.profile` in place, and
schedules, scan metadata, attestation and diff output lose the field.

**Tech Stack:** Python 3.12, pytest (+xdist), SQLite >= 3.35 (`ALTER TABLE DROP COLUMN`),
GitHub Actions, Docker (WSL on this machine), node 22 (dashboard rebuild).

## Global Constraints

Copied from the program plan; every task's requirements include these.

- **Backward compatibility is NOT a constraint.** No users. `--profile-name`, `jmo
  fast|balanced|full`, `profiles:`, the `:fast/:slim/:balanced/:deep` tags go without
  aliases or deprecation.
- **One formatter:** `ruff format`. `make` is not on PATH: run `pre-commit run --all-files`.
- **No `shell=True`.**
- **Conventional commits, and no AI-attribution markers of any kind** (no `Co-Authored-By`,
  no "Generated with", no `Claude-Session:`), in commits and PR bodies.
- **Commit only when Jimmy says.** Never to `dev`; PR into it, squash.
- **Closing keywords go in an individual COMMIT message.** A PR body into `dev` is inert.
- **Gates are numbers through `jmo scan` / `jmo report`, never a bare binary.**
- **Check line endings on every touched file:** `git diff --numstat` must equal
  `git diff --ignore-cr-at-eol --numstat`, compared over the whole diff so renames
  pair. Scripts write with `write_bytes`; a renamed or recreated file keeps its
  predecessor's endings.
- **Run local suites with `PYTHONUTF8` unset**, on `.venv/Scripts/python.exe`.
- **Bounded suite:** `JMO_THREADS=2 .venv/Scripts/python.exe -m pytest tests/ -n 8 -q -m "not smoke and not requires_tools and not docker"`.
- **Read the `windows-2022` job log, never its tick.** Baseline 9890 / 98 / 256 (+2 from #1275).
- **Mutation-test every guard.** Restore from a file backup, never `git checkout --`.
- `--plan` goes **before** the `phase_audit.py` subcommand. `paperclip/` is never touched.

  `yara` and `grype` entries. The top-level `tools:` list is **deleted**, so `TOOL_MATRIX`
  is the one source of the default.
- `jmo build` keeps building the one image; `--variant` and `--all` go.
- Docker tags: semver + `latest` only. Old tags are not deleted, only no longer built
  (spec §3.1).
- `docs/PROFILES_AND_TOOLS.md` is replaced by `docs/TOOLS.md` (the matrix, triggers,
  applicability, install method); `docs/USAGE_MATRIX.md`, `docs/internal/TESTING_MATRIX.md`

```python
def _drop_legacy_profile_column(conn: sqlite3.Connection) -> bool:
    """Drop `scans.profile` from a pre-v2 database, in place.

    ALTER TABLE ... DROP COLUMN rewrites the table without DROP TABLE, so the
    ON DELETE CASCADE foreign keys on findings/scan_metadata never fire (the
    create-copy-drop-rename trap v1_2_0.py documents). SQLite refuses to drop an
    indexed column, hence the index first. Runs from init_database because
    store_scan calls that on every store, and an un-migrated database would
    otherwise reject every insert on the NOT NULL column.
    """
    columns = {row[1] for row in conn.execute("PRAGMA table_info(scans)")}
    if "profile" not in columns:
        return False
    conn.execute("DROP INDEX IF EXISTS idx_scans_profile")
    conn.execute("ALTER TABLE scans DROP COLUMN profile")
    return True
```
